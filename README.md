## 🚀 What I'm Building

### **Zehniq — AI-Powered Learning & Knowledge Workspace**
**Tech Stack:** Next.js 16 · React 19 · TypeScript · Express.js · RAG · OpenAI · Pinecone · Inngest · PostgreSQL · Prisma 8 · Better Auth

An AI-powered learning and knowledge management platform that transforms scattered information into structured, searchable knowledge. Zehniq unifies PDFs, websites, YouTube transcripts, and personal notes into intelligent workspaces, enabling context-aware AI conversations, semantic search, and personalized study material generation.

**Key Features & Technical Highlights**

- **Multi-Source Knowledge Ingestion:** Built a unified pipeline to ingest and process PDFs, websites, YouTube transcripts, and personal notes within organized learning workspaces.
- **Context-Aware AI (RAG):** Implemented document chunking, vector embeddings, and Pinecone-powered semantic retrieval to ground AI-generated responses in user-provided knowledge.
- **Event-Driven Processing:** Integrated Inngest to orchestrate asynchronous document processing, embedding generation, and indexing workflows.
- **Secure, Modular Architecture:** Developed a modular Express.js backend with PostgreSQL, Prisma 8, Better Auth, and workspace-level authorization.
- **Extensible Learning Ecosystem:** Designed the platform to support AI-powered study tools, knowledge exploration, and personalized learning workflows.

**GitHub:** https://github.com/rayyan4533/zehniq
